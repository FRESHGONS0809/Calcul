# Как загрузить свои метки (символы)

## Формат файла

Создайте JSON-файл со следующим форматом:

```json
[
  {
    "id": "уникальный-id",
    "name": "Название метки",
    "category": "Категория",
    "path": "SVG path данные",
    "color": "#цвет"
  }
]
```

### Поля:

- **id** - уникальный идентификатор метки (обязательно)
- **name** - отображаемое название (обязательно)
- **category** - категория для группировки в палитре (обязательно)
- **path** - SVG path данные для отрисовки (обязательно)
- **color** - цвет метки в HEX формате (опционально, по умолчанию #ffffff)

## Пример

Файл `example_custom_symbols.json` содержит пример набора меток:
- Пехота
- Танки
- Артиллерия
- Штаб
- Авиабаза
- РЛС
- Минное поле

## Как использовать

1. Откройте конструктор боевых операций (`конструктор v9.html`)
2. В левой панели нажмите кнопку **"🏷️ Импорт меток"**
3. Выберите ваш JSON-файл с метками
4. Метки появятся в соответствующих категориях в палитре символов

## Примечания

- Если метка с таким же `id` уже существует, она будет обновлена
- Новые метки добавляются к существующим
- Неверные метки (без обязательных полей) пропускаются
- После импорта палитра символов автоматически обновляется
